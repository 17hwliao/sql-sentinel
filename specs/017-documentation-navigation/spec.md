# 文档导航与项目简历整理

**原始需求：** 整理 SQL Sentinel 与 AgentMesh 的文档，但不删除既有资料；产出一份可投递的项目型简历版本。

## 目标

- 仅新增导航页与 README 入口，分类指向既有 README、实施步骤、规格、决策和私有证据，不移动或删除任何文档。
- 生成独立的项目型中文简历，只使用已验证的两项目事实和量化数据；个人信息保留占位，避免虚构。

## 非目标

- 不改运行时代码、协议、实验数据、阶段记录或证据等级；不将私有记录复制为公开事实。
- 不 push/tag，不修改 AgentMesh 或 SQL Sentinel 的历史文档内容。

## 默认假设

- 各项目 README 仍是公开说明的主入口；`docs/README.md` 只承担导航功能。
- `.private/` 继续仅供本机复盘，简历文件放在仓库外的求职材料目录。

## 验收

1. 两仓库均有可点击的文档导航，原有文件路径与内容均不删除。
2. 简历准确写明压测、单次 Ollama 与联桥的范围，未将 L1/false 或替身测试写成生产结论。
3. 两个文档 feature 的 Adaptive 校验与 `git diff --check` 通过。
